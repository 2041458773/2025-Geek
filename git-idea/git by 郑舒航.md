### 对git的认识
Git 是一款分布式版本控制系统，尤其在多人协作开发场景中发挥核心作用，功能十分全面。如果把git看成一个游戏，那么将git的修改进行保存就相当于保存了本地存档，将修改推送到远端仓库即github就相当于上传了云端存档。
作为一个初学者也为其全面且强大的功能所震撼，从其的创建分支功能到远端多人协作无不体现git全面且强大的系统
### 对git的使用
- 回档：git reset
- 创建分支：git checkout -b
- 合并分支：git merge
- 删除分支：git checkout -d
- 切换分支：git switch
- 暂时把当前工作现场“储藏”起来：git stash
### 总结
git具备的功能十分全面，仍需去学习，对应的github具有相当全面的资源等待挖掘
